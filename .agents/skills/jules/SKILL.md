# Google Jules Integration Guide

Google Jules is an autonomous, asynchronous coding agent that connects with GitHub repositories to plan, implement, review, and raise pull requests for software tasks.

## 1. Authentication

Jules API requests require an API key generated from the Jules web app:
* **Settings URL**: [https://jules.google.com/settings#api](https://jules.google.com/settings#api)
* **Header**: `x-goog-api-key: $JULES_API_KEY`
* To configure via CLI:
  ```bash
  npx -y @google/jules-mcp config -k <YOUR_API_KEY>
  ```
  or set in your shell environment:
  ```bash
  export JULES_API_KEY="<YOUR_API_KEY>"
  ```

## 2. Model Context Protocol (MCP) Tools

The `@google/jules-mcp` server exposes the following tools to Antigravity IDE:
* `create_session`: Initiate a new coding task in a repository with a prompt and starting branch.
* `list_sessions`: List active and previous tasks/sessions.
* `session_state`: Inspect the current execution status, plan, and progress of a session.
* `send_reply`: Send messages, clarifications, or feedback to the Jules agent.
* `show_diff`: Retrieve code diffs generated by Jules for the current task.
* `review_changes`: Review code changes and approve/reject implementation plans.

## 3. Direct REST API Endpoints

Base URL: `https://jules.googleapis.com/v1alpha`

### List Connected Sources (Repositories)
```bash
curl -H "x-goog-api-key: $JULES_API_KEY" \
  https://jules.googleapis.com/v1alpha/sources
```

### Create a Session
```bash
curl 'https://jules.googleapis.com/v1alpha/sessions' \
  -X POST \
  -H "Content-Type: application/json" \
  -H "x-goog-api-key: $JULES_API_KEY" \
  -d '{
    "prompt": "<Task description>",
    "sourceContext": {
      "source": "sources/github/<owner>/<repo>",
      "githubRepoContext": {
        "startingBranch": "main"
      }
    },
    "automationMode": "AUTO_CREATE_PR",
    "title": "<Task Title>"
  }'
```

### List Activities in a Session
```bash
curl 'https://jules.googleapis.com/v1alpha/sessions/<SESSION_ID>/activities?pageSize=30' \
  -H "x-goog-api-key: $JULES_API_KEY"
```

### Approve Plan
```bash
curl 'https://jules.googleapis.com/v1alpha/sessions/<SESSION_ID>:approvePlan' \
  -X POST \
  -H "Content-Type: application/json" \
  -H "x-goog-api-key: $JULES_API_KEY"
```
